## ✨ 功能特性

- **一键切换**：输入激活码，自动切换 Claude 账号
- **使用次数管理**：支持激活码使用次数限制
- **无痕模式支持**：完美支持浏览器无痕模式
- **自动验证**：切换后自动验证账号有效性
- **失效保护**：检测到失效账号不扣除使用次数

## 📥 下载安装

### 1. 下载插件

前往 [Releases 页面](https://github.com/wp13461544040/auto-cookie/releases)，下载最新版本的 **extension.zip** 文件。

### 2. 解压文件

将下载的 `extension.zip` 解压到任意文件夹（建议放在不会删除的位置）。

### 3. 安装到浏览器

#### Chrome 浏览器

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 打开右上角的 **"开发者模式"**
4. 点击 **"加载已解压的扩展程序"**
5. 选择解压后的文件夹
6. 安装完成！

#### Edge 浏览器

1. 打开 Edge 浏览器
2. 访问 `edge://extensions/`
3. 打开左下角的 **"开发人员模式"**
4. 点击 **"加载解压缩的扩展"**
5. 选择解压后的文件夹
6. 安装完成！

### 4. 固定插件图标（推荐）

点击浏览器地址栏右侧的 **拼图图标** 🧩，找到 "Claude Account Switcher"，点击 📌 固定到工具栏。

## 📖 使用教程

### 第一步：配置激活码

首次使用需要配置激活码。

1. 右键点击插件图标
2. 选择 **"选项"** 或 **"扩展程序选项"**
3. 在激活码输入框中填入你的激活码
4. 点击 **保存配置**

### 第二步：切换账号

1. 点击浏览器工具栏中的插件图标
2. 点击 **切换账号** 按钮
3. 等待 3-5 秒完成切换
4. 看到"✅ 切换成功"即可使用

### 查看剩余次数

切换成功后会显示：

```
✅ 切换成功！剩余 5 次使用
```

- 每次成功切换会扣除 1 次
- **验证失败不扣除次数**

### 无痕模式使用

插件完美支持浏览器的无痕模式（隐身模式）。

1. 打开无痕窗口
   - Chrome：`Ctrl + Shift + N`
   - Edge：`Ctrl + Shift + N`
2. 在无痕窗口中使用插件切换账号
3. 切换后的账号仅在该无痕窗口生效
4. 关闭无痕窗口后，账号信息自动清除

## ❓ 常见问题

### 1. 插件无法加载？

**检查清单：**
- ✅ 是否启用了浏览器的 "开发者模式"？
- ✅ 选择的文件夹是否正确（包含 manifest.json）？
- ✅ 是否使用 Chrome/Edge 浏览器？

### 2. 切换账号失败？

**可能原因：**
- 激活码输入错误
- 激活码使用次数已用完
- 网络连接问题

**解决方法：**
1. 仔细核对激活码（16-32 位字符）
2. 检查网络连接是否正常
3. 联系管理员检查激活码状态

### 3. 验证失败不扣次数？

**提示信息：**
```
❌ SessionKey 验证失败，此账号已失效（不扣除使用次数），请重试获取新账号
```

**说明：**
- 该账号的 SessionKey 已失效
- **本次切换不会扣除使用次数**
- 系统已自动清理该失效账号
- 重新点击切换会获取新账号

### 4. 无痕模式下切换失败？

**解决方法：**
- 插件已支持自动重试（最多 3 次）
- 无痕模式下可能需要稍长时间，请耐心等待
- 如果仍然失败，请尝试重新切换

## 📊 功能说明

### 状态提示

| 提示 | 说明 |
|------|------|
| ⏳ 切换中 | 正在切换账号，请稍候 |
| ✅ 切换成功 | 账号已切换，显示剩余次数 |
| ❌ 激活码无效 | 激活码错误或已过期 |
| ❌ 验证失败 | 账号失效，不扣次数，重试即可 |
| ❌ 网络错误 | 网络连接失败 |

### 验证机制

- **自动验证**：切换后自动验证 SessionKey 有效性
- **重试机制**：验证失败会自动重试 3 次
- **失效保护**：验证失败不扣除使用次数
- **自动清理**：失效账号自动从后台删除

## 🔐 隐私说明

- 插件仅在切换账号时与服务器通信
- 激活码仅存储在本地浏览器中
- 不收集任何个人信息
- 无痕模式下数据自动清除
