=== Docker Compose 下载失败修复方案 ===

【问题】
curl: (56) OpenSSL SSL_read: error:0A000126:SSL routines::unexpected eof while reading

【原因】
网络不稳定或被限制，GitHub 下载超时


【解决方案】

方案1：使用独立安装脚本
chmod +x install-compose.sh
sudo bash install-compose.sh


方案2：手动使用国内镜像（推荐）
sudo curl -L --retry 3 --retry-delay 5 \
  https://get.daocloud.io/docker/compose/releases/download/v2.24.5/docker-compose-$(uname -s)-$(uname -m) \
  -o /usr/local/bin/docker-compose

sudo chmod +x /usr/local/bin/docker-compose
docker-compose --version


方案3：使用 pip 安装
sudo apt update
sudo apt install -y python3-pip
sudo pip3 install docker-compose
docker-compose --version


方案4：使用 apt 安装（Ubuntu/Debian）
sudo apt update
sudo apt install -y docker-compose
docker-compose --version


方案5：手动下载上传
1. 本地下载：https://github.com/docker/compose/releases/download/v2.24.5/docker-compose-linux-x86_64
2. 上传到服务器：scp docker-compose-linux-x86_64 root@server:/usr/local/bin/docker-compose
3. 设置权限：sudo chmod +x /usr/local/bin/docker-compose


【验证安装】
docker-compose --version

如果显示版本号，安装成功。


【安装成功后继续部署】

cd auto-cookie

# 如果使用 pip 安装的，可能需要更新路径
export PATH="$PATH:$HOME/.local/bin"

# 继续执行部署
sudo bash deploy.sh


【完全手动部署（不使用 docker-compose）】

# 1. 构建后端
cd backend
npm config set registry https://registry.npmmirror.com
npm install
npm run build
cd ..

# 2. 启动 MySQL
docker run -d \
  --name mysql-claude \
  -e MYSQL_DATABASE=claude_switcher \
  -e MYSQL_USER=dev \
  -e MYSQL_PASSWORD=dev123 \
  -e MYSQL_ROOT_PASSWORD=root123 \
  -p 3306:3306 \
  -v mysql-data:/var/lib/mysql \
  --restart unless-stopped \
  mysql:8.0

# 3. 等待 MySQL 启动
sleep 20

# 4. 构建并启动后端
docker build -t auto-cookie-backend ./backend
docker run -d \
  --name auto-cookie-backend \
  -p 3000:3000 \
  -e PORT=3000 \
  -e DB_HOST=172.17.0.1 \
  -e DB_PORT=3306 \
  -e DB_NAME=claude_switcher \
  -e DB_USER=dev \
  -e DB_PASSWORD=dev123 \
  -e NODE_ENV=production \
  --restart unless-stopped \
  auto-cookie-backend

# 5. 运行迁移
docker exec auto-cookie-backend npm run migrate

# 6. 查看日志
docker logs -f auto-cookie-backend


【常用 Docker 命令（不使用 compose）】

# 查看运行状态
docker ps

# 查看日志
docker logs -f auto-cookie-backend
docker logs -f mysql-claude

# 重启服务
docker restart auto-cookie-backend
docker restart mysql-claude

# 停止服务
docker stop auto-cookie-backend mysql-claude

# 删除容器
docker rm -f auto-cookie-backend mysql-claude

# 删除数据卷（慎用）
docker volume rm mysql-data
