## 如何发布到 GitHub

1. 访问：https://github.com/wp13461544040/auto-cookie/releases
2. 点击 "Draft a new release"
3. 创建新 tag：v1.0.0
4. 标题：Claude 账号切换插件 v1.0.0
5. 上传 extension.zip 文件
6. 点击 "Publish release"

## 用户使用流程

1. 从 GitHub Releases 下载 extension.zip
2. 解压到本地文件夹
3. Chrome/Edge 浏览器：
   - 访问 chrome://extensions/ 或 edge://extensions/
   - 开启"开发者模式"
   - 加载解压的扩展
4. 配置激活码：
   - 右键插件图标 → 选项
   - 输入激活码
   - 保存
5. 使用：
   - 点击插件图标
   - 点击"切换账号"
   - 完成！
