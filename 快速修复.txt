=== Docker Compose 版本冲突快速修复 ===

【问题】
TypeError: kwargs_from_env() got an unexpected keyword argument 'ssl_version'

【原因】
pip 安装的是旧版本 docker-compose (1.x)，与新版 Docker 不兼容


【解决方案】

方案1：使用修复脚本（推荐）
cd auto-cookie
chmod +x fix-docker-compose.sh
sudo bash fix-docker-compose.sh


方案2：手动修复（3条命令）
# 卸载旧版本
sudo pip3 uninstall -y docker-compose

# 下载新版本
sudo curl -L https://get.daocloud.io/docker/compose/releases/download/v2.24.5/docker-compose-$(uname -s)-$(uname -m) -o /usr/local/bin/docker-compose

# 设置权限
sudo chmod +x /usr/local/bin/docker-compose

# 验证
docker-compose version


方案3：使用 Docker 插件版本
# 卸载旧版本
sudo pip3 uninstall -y docker-compose
sudo rm -f /usr/local/bin/docker-compose

# 安装插件版本
sudo mkdir -p /usr/local/lib/docker/cli-plugins
sudo curl -L https://get.daocloud.io/docker/compose/releases/download/v2.24.5/docker-compose-$(uname -s)-$(uname -m) \
  -o /usr/local/lib/docker/cli-plugins/docker-compose
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose

# 创建软链接
sudo ln -s /usr/local/lib/docker/cli-plugins/docker-compose /usr/local/bin/docker-compose

# 验证（两种方式都可以）
docker compose version
docker-compose version


方案4：一行命令修复
sudo pip3 uninstall -y docker-compose && sudo curl -L https://get.daocloud.io/docker/compose/releases/download/v2.24.5/docker-compose-$(uname -s)-$(uname -m) -o /usr/local/bin/docker-compose && sudo chmod +x /usr/local/bin/docker-compose && docker-compose version


【修复完成后继续部署】
cd auto-cookie
sudo bash deploy.sh


【如果还是失败】
# 完全清理
sudo pip3 uninstall -y docker-compose docker
sudo apt remove -y docker-compose
sudo rm -f /usr/local/bin/docker-compose /usr/bin/docker-compose

# 重新安装
sudo bash fix-docker-compose.sh
